## 2026-09-12 - UsrYachtEvents: hardcoded max price -> UsrYachtMaxPrice system setting + Sonar rule CR0001
Context: UsrYachtEvents.OnSaving compared UsrPrice against the literal 100000 and restated "100 000 EUR" in the message.
Decision: Externalised the threshold to a new Float system setting UsrYachtMaxPrice (default 100000.00), read via
  Terrasoft.Core.Configuration.SysSettings.GetValue<decimal>(UserConnection, MaxPriceSettingCode, 0m) with the code held in a
  private const string; added an early return when the setting is unconfigured (<= 0) so a 0 fallback cannot reject every save.
Discovery:
- The en-US resource LocalizableStrings.ValueIsTooBig.Value read "No yacht should cost over 100000" with NO {0} placeholder,
  so the existing string.Format(template, "100 000 EUR") silently discarded its argument. Changed to "{0:N0}".
  Only en-US has a translation; the other 27 locales are empty.
- Sys-setting package data = TWO sibling folders, cloned from the existing UsrYachtMinPrice pair:
  Data/SysSettings_<Code>/ (Code + ValueTypeName "Float", 28 Localization files carrying the Name) and
  Data/SysSettingsValue_<Code>/ (FloatValue default, SysAdminUnit = All employees, empty Localization folder).
  Three GUIDs must be freshly generated and substituted: SysSettings descriptor UId == the settings record Id (appears in both
  folders and in every localization file), SysSettingsValue descriptor UId, SysSettingsValue row Id.
- packages/UsrYacht/Files/UsrYacht.csproj compiles Schemas/**/*.cs and Autogenerated/Src/**/*.cs, so `dotnet build -c dev-nf`
  really does validate schema C#. Autogenerated/Src/UsrYachtEventsSchema.UsrYacht.cs holds a gzipped ZipBody of the source -
  never hand-edit it; the platform regenerates it on package load.
- tests/ contains only placeholder.txt - there is no test project in this workspace, so no unit test was added.
Files: packages/UsrYacht/Schemas/UsrYachtEvents/UsrYachtEvents.cs,
  packages/UsrYacht/Resources/UsrYachtEvents.SourceCode/resource.en-US.xml,
  packages/UsrYacht/Data/SysSettings_UsrYachtMaxPrice/, packages/UsrYacht/Data/SysSettingsValue_UsrYachtMaxPrice/,
  sonar/rules/README.md, sonar/rules/CR0001/{CR0001.json,CR0001.html,rule-spec.md}
Impact: Reusable recipe for adding a packaged system setting. Sonar rule CR0001 codifies the three bindings
  (value->setting, code->const, setting->package Data) plus the unconfigured-fallback guard, so the pattern is enforced.
